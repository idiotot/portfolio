**LMS 자료와 과제 일정을 한곳에 모으는 네이티브 학습 도구**

2026년 11월 · 진행 중 · 개인 프로젝트

Rust / SQLite / Iced

## 해결하고 싶은 문제

강의 자료·공지·과제를 따로 찾아보고, 본문에 적힌 날짜와 등록된 마감 시각을 비교하는 과정이 번거로웠습니다. 자료를 과목별로 모으고 마감의 근거까지 확인할 수 있는 화면을 만드는 것이 목표입니다.

## 내가 맡은 작업

개인 프로젝트로 저장 계층, 자료 변환기, 화면 프로토타입을 구현했습니다. AI의 도움을 받아 설계와 코드·오류 분석을 진행하고, 구현 결과는 테스트와 실제 화면 조작으로 확인했습니다.

## 구현 과정과 선택

1. **저장 계층** — Rust와 SQLite로 자료와 상태를 다루는 구조를 작성했습니다. 잘못된 입력과 저장 오류를 확인할 수 있도록 검증과 테스트를 함께 구성했습니다.
2. **자료 변환기** — 기존 카탈로그를 화면과 저장 계층에서 사용할 수 있는 데이터로 변환했습니다. 같은 자료의 중복과 마감 정보의 불일치를 구분하도록 했습니다.
3. **화면 프로토타입** — Rust로 작성한 데이터 처리 코드와 연결하기 위해 Iced를 선택했습니다. 보관함·일정·마감 검토 화면을 구현했습니다.
4. **동작 확인** — 가상 자료로 검색, 과목 필터, 읽음·보관 표시, 근거 화면 이동을 확인했습니다.

## 배운 점과 남은 한계

날짜를 보여주는 것뿐 아니라 **어디서 확인한 날짜인지 함께 보존하는 것**이 중요하다는 점을 배웠습니다. 데이터의 상태와 화면의 상태를 구분해야 완료 여부를 과장하지 않을 수 있었습니다.

현재 화면은 가상 자료 기반의 프로토타입입니다. 실제 LMS 로그인·온라인 동기화·PDF 열람·AI 호출과 화면의 영구 저장은 아직 연결하지 않았습니다. 작은 창을 위한 배치도 개선이 필요합니다.

다음에는 자료 목록 조회와 읽음 상태를 실제 저장 계층에 연결하고, 재실행 후 복원과 오류 처리를 확인할 계획입니다.

## 작업 기록

이 페이지의 화면은 개인 프로젝트에서 실행·캡처한 가상 자료 프로토타입입니다. 실제 강의 자료나 계정 정보는 포함하지 않습니다.
