## 안녕하세요, idiotot입니다

일상에서 직접 겪는 불편을 개발 주제로 삼고 있습니다. 현재는 강의 자료와 과제 일정을 정리하는 개인 프로젝트 **NAVI Study**를 진행하고 있습니다.

## 관심 분야

관심 분야는 **학습 도구와 네이티브 데스크톱 앱**입니다. 여러 곳에 흩어진 자료를 찾고, 서로 다른 마감 안내를 확인하는 과정을 줄여보고 싶어 이 분야를 공부하고 있습니다.

## 기술과 실제 적용

NAVI Study에서는 Rust로 데이터 검증과 변환을 구현하고, SQLite 저장 계층을 작성했습니다. Iced 화면에서는 검색과 필터, 읽음·보관 표시가 실제 조작에 따라 바뀌는지 확인했습니다. 이 포트폴리오는 Hugo와 GitHub Actions를 사용합니다.

현재 앱 화면은 가상 자료를 사용합니다. 실제 자료 연결과 영구 저장을 UI에 적용하는 작업은 다음 단계입니다.

## 학습 목표와 다음 행동 {#learning}

**목표는 자료를 안정적으로 저장하고 다시 읽을 수 있는 학습 도구를 만드는 것**입니다.

1. 화면의 자료 목록을 저장 계층의 조회 결과와 연결합니다.
2. 읽음·보관 상태를 저장하고 앱 재실행 뒤 복원되는지 검사합니다.
3. 좁은 창에서도 내용을 읽을 수 있도록 화면 배치를 개선합니다.

작동 범위를 분명히 기록하고, 확인하지 않은 기능은 완료로 표현하지 않으려 합니다.
