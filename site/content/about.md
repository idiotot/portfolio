## 학습 배경 {#안녕하세요-idiotot입니다}

컴퓨터공학을 전공하는 **idiotot**이다. 전공 수업에서는 Java의 클래스와 상속을 중심으로 객체지향 프로그래밍을 학습하고 있다. 개인 개발 활동에서는 Rust 기반 데스크톱 프로그램의 구현과 검증을 수행하고 있다.

## 관심 분야 {#관심-분야}

주요 관심 분야는 강의 자료와 과제 일정의 통합 관리이다. LMS의 자료·공지·마감 정보를 여러 화면에서 반복적으로 확인해야 하는 과정을 줄이기 위해 NAVI Study를 개발하기 시작하였다.

이와 관련하여 로컬 파일 처리, 데이터 저장 및 데스크톱 GUI 구성을 학습하고 있다.

## 적용 기술 및 학습 내용 {#기술과-실제-적용}

### 프로젝트에 적용한 기술

- **Rust**: 자료 저장 모듈, 카탈로그 변환기 및 GUI 상태 처리 코드를 구현하였다.
- **SQLite**: 자료 레코드와 관측 시각을 저장하는 모듈을 구현하였다. GUI와의 연계는 아직 수행하지 않았다.
- **Iced**: 과목별 자료 목록, 검색·필터, 과제 일정 및 마감 검토 화면에 적용하였다.
- **Hugo · GitHub Actions**: 본 포트폴리오의 페이지 구성과 자동 배포에 사용하였다.

### 현재 학습 중인 내용

전공 수업의 Java 객체지향 프로그래밍 실습을 진행하고 있다. 개인 프로젝트의 후속 학습 과제는 화면의 선택 항목과 저장 레코드의 연결, 읽음·보관 상태의 영구 저장 및 재실행 후 상태 복원이다.

## 후속 개발 및 학습 목표 {#learning}

현재 NAVI Study는 저장·변환 모듈의 자동 테스트와 가상 데이터 기반 GUI의 상태 처리 검증을 수행한 단계이다.

후속 작업에서는 자료 목록 조회 결과를 GUI에 연계하고, 읽음·보관 상태에 필요한 저장 구조를 정의할 계획이다. 이후 재실행 시 상태 복원과 오류 처리를 검증하며, 작은 창에서도 자료를 확인할 수 있도록 화면 배치를 개선하고자 한다.
