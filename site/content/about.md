## 학습 배경 {#안녕하세요-idiotot입니다}

컴퓨터공학을 전공하는 대학생 **idiotot**입니다. Java로 클래스와 상속을 다루는 수업 실습을 하고, 개인 프로젝트로 Rust 데스크톱 프로그램을 개발하고 있습니다.

## 관심 분야 {#관심-분야}

강의 자료를 과목별로 찾고 과제 일정을 확인하는 도구에 관심이 있습니다. LMS의 자료·공지·마감 정보를 여러 화면에서 확인하는 과정을 줄여보고 싶어 **NAVI Study**를 시작했습니다.

웹 화면뿐 아니라 로컬 파일과 데이터를 다루는 데스크톱 프로그램도 공부하고 있습니다.

## 사용한 기술과 학습 중인 내용 {#기술과-실제-적용}

### 프로젝트에서 사용한 기술

- **Rust**: 자료 저장 모듈, 기존 카탈로그 변환기, 화면의 상태 처리 코드를 작성했습니다.
- **SQLite**: 자료 레코드와 관측 시각을 저장하는 모듈을 구현했습니다. GUI와의 연결은 아직 하지 않았습니다.
- **Iced**: 과목별 자료 목록, 검색, 과제 일정과 마감 검토 화면을 만들었습니다.
- **Hugo · GitHub Actions**: 이 포트폴리오의 페이지 작성과 자동 배포에 사용했습니다.

### 수업과 다음 개발에서 공부하는 내용

Java의 클래스·상속 등 객체지향 프로그래밍을 실습하고 있습니다. 개인 프로젝트에서는 화면에서 선택한 항목을 저장 레코드와 연결하고, 읽음·보관 상태를 재실행 후에도 유지하는 방법을 다음 과제로 두고 있습니다.

## 최근 작업과 다음 목표 {#learning}

현재 NAVI Study의 저장·변환 모듈을 테스트하고, 가상 자료로 GUI 동작을 확인하는 단계입니다.

다음에는 자료 목록 조회부터 화면에 연결하려고 합니다. 이후 읽음·보관 상태의 저장 구조를 정하고, 재실행 뒤 복원되는지 확인할 계획입니다. 작은 창에서도 자료를 읽을 수 있도록 화면 배치도 개선하려 합니다.
